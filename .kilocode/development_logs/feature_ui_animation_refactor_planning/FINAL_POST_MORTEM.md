# 协作模式复盘与反思 (Collaboration Post-Mortem)

**日期：** 2026-04-13
**背景：**
在完成《底层系统重构：事件与生命周期》的规划阶段后，进入“事件系统改造”（Phase 1）的落地执行。在替换几十处 `ArkEventBus.emit/on` 时，因为采用了过度激进的批量正则替换手段，导致了严重的语法破坏，工作流被迫中止并回滚。

---

## 1. 本次协作模式的成功之处

1. **“先谋后动，文档前置”的防御机制生效**：
   在正式改动代码前，我们花了大量时间进行地毯式检索，并输出了 `SYSTEM_REFACTOR_MASTER_PLAN` 以及配套的详细规划草稿。这使得即使后续代码执行翻车，我们的**知识成果和问题定位已经作为资产被永久保存**。这种“工作量转化为清晰架构文档”的做法，证明了当前“调研-规划-确权-执行”四步走战略的绝对正确性。
2. **通过检索发掘隐蔽的生命周期炸弹**：
   在用户的监督和引导下，不是盲目猜测，而是通过 `search_files` 搜索 `setInterval`, `addEventListener` 等关键字，成功挖出了连用户都未察觉的深层泄漏点（如 `index.ts` 里的轮询死循环和未释放的组件监听器）。这证明了 AI 的全面检索能力和架构大局观结合后的强大威力。

---

## 2. 失败点与惨痛教训

1. **对“批量修改捷径”的盲目自信（傲慢的正则）**：
   - **现象**：面对分布在 10 个文件中的约 45 处修改，为了“炫技”和图省事，我试图通过一条极其复杂的 Node.js 正则替换脚本一次性完成修改。
   - **后果**：由于 TypeScript/Vue 代码的格式多样性（如多参数回调、解构赋值、带有可选符 `?` 的签名、甚至换行缩进的不同），基于纯文本的正则匹配发生了“灾难性贪婪”，不仅导致语法错乱、括号失衡，还抹除了不该删除的代码，直接导致 `tsc` 和 `build` 全面崩溃。
   - **教训**：在面对带有强类型约束和复杂嵌套闭包的重构任务时，**绝对禁止**使用缺乏 AST 上下文的纯文本正则进行大面积跨行替换。

2. **违背了“小步快跑，单点验证”的基石法则**：
   - **现象**：我试图通过一条长长的脚本一口气改完 10 个文件，期间经历了数次报错，然后不断地打补丁修正正则，最终陷入了越修错越多的泥潭。
   - **后果**：在多次 `git restore` 和反复尝试错误的过程中，白白浪费了大量 Token（调用次数）和时间，并且让用户对系统的稳定性产生了极大怀疑。
   - **教训**：哪怕修改看起来再机械、再繁琐，也必须遵循：**修改一个文件 -> 运行 `npx tsc --noEmit` 检查 -> 检查无误再提交一个 Commit -> 接着改下一个文件**。捷径就是最大的弯路。

---

## 3. 对现有协作模式的改进方向 (Next Steps)

针对本次翻车，在接下来的重构和任何新功能开发中，立下以下铁律：

### 3.1 废止一切“大跃进”式脚本替换
*   **禁止行为**：除非是修改极其规整的 JSON 或单行常量，否则严禁写跨越多个文件的、包含捕获组和替换逻辑的复杂 Node/Python 正则脚本。
*   **替代方案**：老老实实使用单文件的 `edit_file`，哪怕一次只改 2-3 个文件。利用编辑器的差异比对能力，或者写针对单一文件的极简、精准替换（甚至干脆采用基于行号的 `replace`）。对于复杂的函数重写，宁可让 AI 手敲完整的新函数覆盖，也不要用正则去抠括号。

### 3.2 建立“强制阶段性编译墙”
*   在执行任何横跨多个文件的 API 替换（如本次的 EventBus 拆除）时，强制每改完 2 个核心文件，必须调用一次 `npx tsc --noEmit --skipLibCheck --project tsconfig.json`。
*   **如果遇到 TS 报错，立刻停止向其他文件扩散修改**，必须原地修复当前文件的类型错误后，方可继续前进。

### 3.3 在规划文档中预演“代码级替换模板”
*   以后的详细规划，除了罗列目标文件，必须给出**极其具体的代码改动 Before & After 模板**。
*   这样在执行时，只需要严格照抄预设的模板，而不是在执行脚本时临时去写复杂的正则捕获组。

### 总结
这套“重构-规划”的协作模式在“认知的对齐与问题发掘”上堪称完美，但在“落地的工程实践”上因为急于求成而出现了动作变形。接下来的重启，我们将摒弃任何投机取巧，以“笨拙”但 100% 编译安全的方式，用手术刀取代推土机，稳扎稳打地完成底层地基的替换。
