# 陆行舰模拟生存游戏 (代号: Project Landship) - 概念企划书

## 1. 核心概述 (Executive Summary)
- **游戏类型**: 轻量级 3D 模拟经营 (Base Building) + 快节奏末日生存 (Survival)
- **核心定位**: 商业化独立游戏。作为 Web 端同人 AVG 项目的“精神与技术续作”，继承其底层数值框架与状态机设计，但剥离重度 AI 依赖，转向纯粹的玩法驱动。
- **核心灵感**: 《明日方舟》罗德岛陆行舰机制 + 《冰汽时代》(Frostpunk) / 《远方：孤帆》(FAR: Lone Sails) 的移动生存体验。
- **开发规模**: 贴合个人独立开发（Solo Dev）极限，主打中小型体量、高重玩价值（Roguelite 元素），迎合当下碎片化、快节奏的市场需求。

## 2. 与同人 AVG 项目的边界与继承关系
- **剥离重度 AI 依赖 (Cost Control)**：考虑到买断制（B2P）游戏内置 LLM 带来的持续 API 计费灾难，本项目在运行时不再高度依赖 AI 实时生成文本。AI 技术主要前置于**开发期**（用于生成海量的遭遇战剧本文本、粗糙 3D 占位模型生成）或仅作为极轻量级的动态氛围驱动。
- **继承核心资产 (Tech Transfer)**：同人 AVG 开发期积累的宝贵资产——**“事件分发系统、MVU 状态机、干员数值管理框架、资源流转逻辑”**——将 1:1 迁移至本项目的 C# 后端，成为驱动 3D 陆行舰运转的底层核心。

## 3. 核心玩法循环 (Core Gameplay Loop)
1. **大地图航行与路线抉择 (Macro)**: 3D 视角的陆行舰在程序化生成的无缝大地图（或节点网格）上航行。玩家需要规划路线以躲避天灾风暴，寻找废墟节点收集资源。
2. **舰内拼装与快节奏调度 (Micro)**: 
   - 玩家可模块化拼装、升级舰船的各个舱室（动力室、生态园、加工站）。
   - 面对突发危机（如引擎过热、外敌跳帮），玩家需要像《FTL: 超越光速》一样，在不同舱室间快速调度船员进行抢修与防御。
3. **随机事件与资源博弈**: 到达节点触发基于状态机的随机事件（复用 AVG 框架）。事件的成功率与收益由当前的舰船科技树与船员属性决定。

## 4. 美术与资产策略 (Art & Asset Strategy)
- **视觉重心**: 放弃沉浸式长篇视觉小说路线，转向直观的 3D 表现。
- **美术风格**: 采用低多边形（Low-Poly）或风格化渲染（Cel-Shading）。利用技术美学（高对比度 UI、粒子特效、动态光影）掩盖个人开发者在 3D 高模/贴图精度上的不足。
- **资产获取**: 优先使用成熟的 3D 资产商店模型进行拼凑与二次修改，结合 AI 工具快速产出 2D UI 与贴图。

## 5. 技术演进与引擎路线 (Technical Roadmap)
- **Phase 1: 纸面原型与底层逻辑验证**
  - 在当前同人 AVG 项目中，完善基于 TypeScript/C# 的底层资源调度和状态机逻辑。
- **Phase 2: 3D 核心玩法切片 (Vertical Slice)**
  - 转入 Unity/Godot 4 引擎。实现 3D 陆行舰的移动、舱室搭建与 UI 交互的白盒测试（Whitebox Demo）。
  - 将同人项目的状态机库（DLL / 脚本）接入 3D 环境。
- **Phase 3: 体验打磨与量产**
  - 引入完整的 3D 美术资产，完成核心循环的闭环。优化操作手感，确保游戏符合“轻量、快节奏”的市场定位。
