# Phase 2: Godot 引擎破冰与最小可行性产品 (MVP)

## 核心目标
从零开始安装并熟悉 Godot 4（双精度版）。通过实现一个极其简陋但闭环的小游戏，掌握 Godot 的 UI 交互、3D 渲染管线、基础物理和脚本生命周期。

## 注意事项与避坑指南
- **警惕引擎迷失**：对于前端转游戏的开发者，最容易迷失在满屏的渲染参数（Shader、光照、材质）中。这阶段**画面越丑越好**，只要逻辑连通就是胜利。绝对不要在这个阶段去研究怎么做二次元卡通渲染。
- **理解 Godot 的生命周期**：花一晚上的时间彻底弄懂 `_process(delta)` 和 `_physics_process(delta)` 的区别。前者用于渲染和输入，后者用于所有涉及物理和寻路的计算。这是游戏不卡顿的命脉。
