> **文档定位**: 逆向工程与 UI 交互视图全景盘点。汇总侧边栏及主弹窗中【概览】、【配置】、【功能】、【工具】与【开发者】五大模块共 11 个核心页面的物理功能与业务逻辑。

## 一、 概览模块 (Overview)

### 1. 仪表盘 (Dashboard)
- **业务定位**：插件全局运行状态监控与快捷开关调控中心。
- **核心功能与业务逻辑**：
  1. **运行概览监控 (Status Monitor)**：
     - **API 连接状态**：显示当前连接配置及 API 预设选中情况（如跟随酒馆主 API 或独立 API 预设）。
     - **表格更新动态**：监控哪些表格已满足自动/首次更新条件及其待触发状态。
     - **SQL 模式状态**：实时显示当前存储底座（原生 JSON 模式还是 SQLite 模式）。
     - **高级子系统状态**：显示“交火向量”检索模块激活状态，以及前端 Error 级别日志捕获。
  2. **全局开关切换 (Global Control Switches)**：
     - 提供“基础设置”与“高级设置”分层切换。
     - **飞行模式**：开启后抑制剧情推进发包，并在大总结合并时隐藏已归退纪要。
     - **自动更新**：全局切换表格变异发包开关（测试或自由挥发时可一键关闭）。
     - **静默提示框**：关闭弹窗通知，仅保留核心提示与浮窗。
     - **0TK 占用模式**：控制纪要概览是否占用上下文 Token。
     - **开启流式输出**：控制次级/主发包是否边生成边流式返回。

## 二、 配置模块 (Configuration)

### 2. 填表工作台 (Fill Workbench)
- **业务定位**：结构化表格更新的控制台、自动调度配置与手动发包冲刷中心。
- **核心功能与业务逻辑**：
  1. **表格状态监控 (Table Status Monitor)**：
     - 实时列出当前聊天下的所有表格（全局数据表、主角信息表、重要角色表、主角技能表、背包物品表、任务与事件表、纪要表、选项表）。
     - 动态展示每张表的更新频率、未记录楼层数、上次更新时机与下次触发倒计时。
  2. **自动更新设置 (Auto Update Settings)**：
     - 支持指定填表专用 **API 预设**。
     - 设置**自动填表间隔**（如“每 1 层：最及时”）。
     - 开启“最新层不填表”缓冲区，防止最新输出未沉淀即被提前误填。
  3. **手动填表控制 (Manual Mutation Trigger)**：
     - 灵活指定“手动处理最近 N 层”以及“每 N 层合并为一次填表”。
     - 支持勾选参与更新的具体表格（支持一键全选/全不选）。
     - 可注入“本次填表附加要求”（额外 Prompt 限制）。
  4. **表格模板预设 (Table Template Preset)**：
     - 查看与切换当前聊天关联的快照模板及全局预设。
     - 提供一键打开“可视化表格编辑器”入口，进行数据直观修改。

### 3. 填表规则 (Fill Rules)
- **业务定位**：控制填表 AI 在变异与生成 SQL 时的上下文输入范围、语法过滤规则与 Prompt 自定义。
- **核心功能与业务逻辑**：
  1. **附加世界书条目**：设置填表时是否允许附带世界书（跟随角色卡或手动筛选特定的世界书主册与条目）。
  2. **标签与语法筛选 (Tag & SQL Filtering)**：
     - **丢弃纯越权 SQL 语句**：拒绝并丢弃试图修改非目标表或无法归属的独立 SQL。
     - **仅识别最后一个 `<tableEdit>` 标签**：忽略 LLM 在思维链/草稿中产生的旧 SQL，仅提取最终确定块。
     - 支持配置正则表达式式的“提取规则”与“排除规则”。
  3. **填表提示词管理**：自定义或重置填表 AI 的系统提示词（System Prompt）。
  4. **写入目标世界书**：指定填表结果在更新回写时的目标世界书容器（如角色卡绑定世界书）。

### 4. 剧情推进 (Plot Advancement)
- **业务定位**：管理“天之音/前置侦察兵”时间线记忆召回与剧情线推进的预设及上下文绑定。
- **核心功能与业务逻辑**：
  1. **剧情推进预设管理**：
     - 配置与切换剧情推进专用的 Prompt 预设（如时间线召回模式）。
     - 绑定独立的“剧情推进 API 预设”，实现主模型与前置推理模型解耦。
  2. **剧情推进世界书检索范围**：
     - 绑定剧情推进检索时的世界书来源（跟随角色卡或手动挑选），精准筛选用于语义/时间线分析的条目库。

### 5. Agent (智能体世界书接管)
- **业务定位**：高阶多 Agent 决策引擎与世界书“绿灯”动态接管/Skill 化管理中心。
- **核心功能与业务逻辑**：
  1. **Agent 世界书总控**：
     - 三档模式切换：**关闭** / **仅观察** / **Agent 接管**（接管后在剧情推进时接管世界书条目的放行与过滤，完毕后恢复快照）。
     - 绑定独立的“Agent 决策 API”与“Agent Skill 化 API”。
  2. **高级动作与 Skill 化 (Skillification)**：
     - 提供“清理并初始化”、“一键 Skill 化”与“清除 Skill 化”动作，将传统世界书条目转化为结构化 Agent Skill。
  3. **世界书作用域与条目批处理**：
     - 绑定作用域来源，支持对选中的世界书条目批量执行 Skill 化转换。

### 6. API (独立 API 预设库)
- **业务定位**：解耦主模型 API 与次级功能 API，支持多模型/多服务商的配置预设池。
- **核心功能与业务逻辑**：
  1. **API 预设管理**：
     - 允许创建、配置、选择和删除独立的 API 预设（如将填表分配给响应极快的小模型，而主模型使用大语言模型）。
     - 支持设置当前默认预设或全局默认预设，为填表、剧情推进、Agent 等不同子系统提供独立的模型算力调度。

## 三、 功能模块 (Functionality)

### 7. 智能续写 (Auto Continuation)
- **业务定位**：后台自动化循环发包与无人值守 AI 挂机/挂刷引擎。
- **核心功能与业务逻辑**：
  1. **循环条件控制**：
     - **标签检查**：指定回复中必须包含的标签（如 `content`, `thinking`），缺失时自动触发重试。
     - **运行参数**：配置每次续写间隔延时（秒）、总运行时长（分钟）、失败重试上限及 AI 上下文读取楼层数。
  2. **循环提示词列表**：可预设多条循环驱动 Prompt，按顺序轮询下发。
  3. **运行状态机**：显示当前续写状态（运行中/未运行），提供一键启动/停止控盘。

### 8. 外部导入 (External Import)
- **业务定位**：将外部小说、大纲或长文本文件批量拆分、编码转码并自动注入 SQLite 表格或世界书。
- **核心功能与业务逻辑**：
  1. **文件拆分与编码**：支持选择文件编码（如 GBK、UTF-8）及单段字符切片上限（如每段 10,000 字）。
  2. **目标表格映射**：勾选切片数据需要自动解析并写入的具体关系表（如主角表、纪要表、任务表等 8 张核心表）。
  3. **写入目标世界书**：筛选并指定导出的目标世界书容器，提供“选择并拆分”、“写入”、“清空缓存”与“删除条目”批处理操作。

## 四、 工具模块 (Tools)

### 9. 数据管理 (Data Management)
- **业务定位**：特定聊天的表格数据快照备份/恢复，以及历史楼层脏数据的范围清理。
- **核心功能与业务逻辑**：
  1. **Checkpoint 备份与恢复**：
     - **导出 Checkpoint**：打包导出当前聊天隔离标识（Isolation Key）下的全部 AI 楼层数据、表格模板及指导表。
     - **导入 Checkpoint**：一键清空并重构当前激活聊天的本地表格快照，实现存档跨环境迁移。
  2. **删除与清理 (Data Pruning)**：
     - **自动清理**：设置“保留数据层数”（如 100 层），更新完成后静默自动擦除超出的旧楼层插件数据（不影响酒馆原生聊天正文）。
     - **范围手动删除**：自由指定起始至终止 AI 楼层范围，执行局部填表数据清理或一键“删除所有本地数据/恢复默认配置”。

### 10. 高级工具 (Advanced Tools)
- **业务定位**：数据库底层直接交互控制台与全系统实时运行日志诊断中枢。
- **核心功能与业务逻辑**：
  1. **SQL 控制台 (SQL Console)**：
     - 实时显示 SQLite 原生 Provider 状态（可用/不可用）。
     - 提供“查看所有表”与“查看表结构 (DDL)”快捷入口。
     - 支持直接输入并执行标准 SQL 语句（如 `SELECT * FROM 表;` / `UPDATE ...`），显示执行结果与历史记录。
  2. **运行日志 (Runtime Diagnostics)**：
     - 捕获并保留最近 2000 条系统运行日志，支持按日志级别（Debug/Warn/Error）及特定子系统模块进行过滤与搜索。
     - 提供暂停滚动、导出日志文件、清空日志及实时采集开关。

## 五、 开发者模块 (Developer)

### 11. 开发者选项 (Developer Options)
- **业务定位**：实验性功能门控（Feature Gating）、低级协议响应切换与并发压测参数调优。
- **核心功能与业务逻辑**：
  1. **开发者 Gated 字段开关**：
     - 开启/关闭“剧情推进预设匹配替换字段”、“交火模式（向量召回参数与归档面板）”以及“酒馆扩展菜单旧 UI 入口”。
  2. **填表高级选项**：
     - **严格 JSON 填表响应**：开启后由松散的 `<tableEdit>` 标签模式切换为输出标准结构化 JSON 包裹 SQL 脚本模式，适配不支持自由标签的次级小模型。
  3. **填表执行参数调优**：
     - **最大并发更新组数**：控制同一时刻允许并发调用 API 执行填表变异的 UpdateGroup 数量（提升效率或降低 API 压测风险）。
